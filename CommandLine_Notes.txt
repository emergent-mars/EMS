# Navigation
cd <folder> = to specific directory
cd .. = go to parent directory
cd - = go to last directory
pwd = show current path
ls = see contents of directory
ls -a = see contents including hidden contents

**sudo** [command] to run as admin
> sudo apt update = apply new shit
> sudo apt get remove [application] = to uninstall something

`monitor cpu temp in terminal command`
watch -n 2 acpi -t

`mic and audio settings`
pavucontrol

`emacs` [filename] to open in emacs

git add "<filename>" to update what will be committed
git restore "<filename>" to discard changes in working directory
git commit -m "<filename>" to add a changed file to main branch to commit
git commit -a "<filename>" to add and commit at the same time
git commit -m "message" to commit with the message directly without opening a window
`git push origin main` to actually update main branch of the repository

git checkout <branch-name> to check if local is up to date with remote
git pull origin <branch-name> to apply remote changes to local repo


./a.out to run cpp code in /EMS

compile code
g++ <cpp file> -o <executable name>
