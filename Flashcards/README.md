Simple program to test the user's knowledge of dosages for meds in the NREMT and Denver Metro drug lists. It provides the name of the drug, a description of it, indications, contraindications, and then prompts the user for the correct dosages.

Runs in terminal, download and compile .cpp file. If you don't want to use terminal, copy and paste everything in 'meds_flashcards.cpp' into an online c++ compiler such as https://www.onlinegdb.com/online_c++_compiler.
